# Domain glossary
- Orb: one timed note in one lane.
- Chart: ordered orb pattern for a track.
- Track: original music and its chart.
- Judgement: Perfect, Good, Close, Miss, or empty press.
- Combo: consecutive scored orbs since a miss or empty press.
- Offset: milliseconds subtracted from input time; positive means compensation for late presses.
- Run: one attempt from count-in to results, including pauses.
